# dotfiles
Personal dotfiles for my Arch + Hyprland setup

## Packages

### Mandatory
```
hyprland           // window manager
elephant           // data provider and executor
walker             // application launcher
swaync             // notification daemon
nautilus           // file browser
alacritty/ghost    // terminal emulator
clammy             // status bar
matugen            // dynamic theming engine
python-pywal       // wallpaper color extractor
pywalfox           // firefox theme generator
qt5ct              // qt theme engine
qt6ct              // qt theme engine
gtk4               // gtk4 theme engine
slurp              // region selector
grim               // screenshot tool
hyprpicker         // color picker
hyprpaper          // wallpaper manager
wireplumber        // multimedia router
pavucontrol        // volume control
uwsm                // universal wayland session manager
```

### Optional
```
zed                 // code editor
todosh               // todo manager for terminal
mpv                // media player
mpd                // music player daemon
imv                // image viewer
fish               // shell
hyprconfig         // hyprland config manager
```
